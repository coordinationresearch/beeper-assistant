# For agents working in this repo

Which one are you?

- **Someone asked you to install this skill for them.** Follow [SETUP.md](SETUP.md). It is the whole procedure.
- **Someone asked you to use the skill.** Read [SKILL.md](SKILL.md).
- **Someone asked you to change the skill's code.** Read the last section of [README.md](README.md). Run `node --test tests/*.test.mjs` before and after. The tests never touch a real account, and neither should you while developing.
